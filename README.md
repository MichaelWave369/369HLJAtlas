# Φ 369 HLJ Atlas

**Hope · Love · Joy | A bridge between ancient wisdom and modern discovery.**

> We do not need to believe the same things to build a world where we can all belong.

Open-source research index containing **179 founding topics** in **nine realms**, explored through scientific, experimental and cultural lenses. Every topic initially has `reviewStatus: not-reviewed`. Listing an extraordinary claim is **not** proof of its mechanism or efficacy.

## HLJ-001

- Fully searchable realm and topic registry with detailed inquiry cards.
- Fourteen explicitly provisional cross-topic relationships.
- Direct gateways to existing independent Phi369 Labs research projects.
- Responsive, accessible, no-account static interface; zero production dependencies, trackers, or backend.
- Node tests and GitHub Pages workflow.

## Preview

Serve `site/` using a local HTTP server, such as `python -m http.server 8000 -d site`, then open `http://localhost:8000`. Browsers normally block local `file://` fetches.

Run `npm test` with Node 20+.

## Data

`site/data/topics.json`: founding-topic registry. `site/data/connections.json`: narrow and provisional links, not claims of causation. `site/data/labs.json`: independently maintained project gateways. See `docs/RESEARCH_CHARTER.md` and `docs/ROADMAP.md`.

## Guardrails

Separate scientific evidence from hypothesis, personal experience and cultural meaning. Health-related topics are educational, not medical advice. No psychiatric, biological, psychic or supernatural effect is asserted merely through inclusion. This geometric artwork is decorative, not a physical frequency generator.

**HLJ refers to Hope, Love and Joy**, not a claimed partnership with Hope LoveJoy, HOPEvolve or another individual. Collaboration requires explicit consent.

MIT licensed. Built to complement the PhiOS / Phi369 Labs ecosystem without replacing existing laboratories.

## HLJ-002 — The Research Library

- Ten editorial evidence dossiers, each with a precise focus question, narrow supported finding, evidence boundary, alternative explanations, next test and safety/cultural notes.
- Nineteen linked external references from universities, museums, standards institutions, scientific papers and health evidence services. Some are directly supporting sources; some are context or counterevidence, as the prose explains.
- Classification labels describe each **specific dossier's focus**, not all claims associated with a topic.
- Accessible browsing, evidence-type filter, selectable research cards, side-by-side comparison and shareable `?dossier=<topic-id>` links.
- No remote runtime source fetching; source metadata ships with the site. Third-party pages open only when you click.

These are *curated starting points*, not a systematic review. No individual or outside site is described as an endorsing partner.

## HLJ-003 — Knowledge Constellation

- All 179 topics rendered as deterministic nodes around nine editorial realm hubs.
- Only fourteen previously documented provisional relations appear as dashed connections; ten gold source pins link to starter dossiers.
- Search, realm selection, research-only filtering, detailed source inspector, zoom and pan, and keyboard-accessible topic index.
- Session-only private research notebook with explicit local JSON export, no automatic storage or network upload.
- Shareable `?topic=<id>#constellation` URLs and dedicated contract/integrity tests.

**Important:** Positions illustrate taxonomy, not quantitative closeness. Relationship lines are not assertions of causality. Starter dossiers do not replace independent source review.

## HLJ-004 — Review-before-apply Lab Bridge

HLJ Atlas now recognizes **four precise export shapes** from AquaCymatics369 and PHI369 Element Spiral Atlas. Users select a small local JSON file, inspect the *producer-declared* details, explicitly approve an allowlisted summary, and optionally associate a topic. Approved summaries remain in memory only until explicitly exported in a portable JSON research packet or cleared.

This is **manual interoperability** only. It does not access any other app's browser storage, upload source files, embed third-party scripts, mutate outside projects, or authenticate laboratory findings. The source-by-source contract audit and manual acceptance guide are in [docs/LAB_BRIDGE_CONTRACTS.md](docs/LAB_BRIDGE_CONTRACTS.md).

## HLJ-005 — The Shasta Institute bridge

A six-stop conceptual visitor map introduces The Open Door, Geometry Garden, Resonance Studio, Evidence Library, Consciousness Observatory, and Joy Commons. The map describes a **future educational vision**, not a built or approved facility. A source-documented PhiOS gateway links to independent Web, Mobile, XR and PhiXRCommons projects; these are user-initiated links and not native installations.

Click **Export passive XR scene JSON** to build a strictly bounded `phi.spatial.scene.v1` file (nine realm spheres and ten synthetic research markers). Import it explicitly via PhiOS XR's existing ΦSpatial Scene Bridge and confirm before display. No personal notes or measurements are included, and there is no automatic transfer, tracking or XR authority. See [docs/SHASTA_INSTITUTE_GATEWAY.md](docs/SHASTA_INSTITUTE_GATEWAY.md) for exact schema and Quest acceptance gates.

## HLJ-006 — Living Research Laboratory

Three guided, zero-dependency educational models: 1D fixed-string standing waves, convex Platonic-solid Euler counts, and reproducible seeded fair-coin null-model trials. Visitors write a prediction, run a mathematical model, record an observation and a competing interpretation, then explicitly capture up to 12 records for local-only JSON export. Source references are contextual, not measurements or proof. See [docs/LIVING_RESEARCH_LAB.md](docs/LIVING_RESEARCH_LAB.md). No source-project code is copied or modified.
