# HLJ-006 — The Living Research Laboratory

This is an **educational simulation and mathematical comparison workspace**. It is not a laboratory data-collection platform, autonomous scientific investigator, paranormal test, medical diagnostic, or claim of experimental discovery.

## The three protocols

1. **Standing-Wave Studio**: fixed-end ideal 1D string, fixed assumed wave speed 120 meters per second, length 0.5–3 m and mode 1–6. Formula is \`f_n = n v/(2L)\`. Returns nodes, antinodes, wavelength, frequency, and a calculated SVG mode shape. The related Cymatics/Chladni sources are *context*, not proof that this string model reproduces plates or provides therapeutic benefit.
2. **Five Solids, One Invariant**: the five convex regular Platonic solids and exact counts for vertices, edges, faces. Verifies \`V − E + F = 2\`. This is mathematical reasoning, not an assertion about energetic properties.
3. **Chance & the Null Model**: deterministic seed-controlled pseudorandom toy sequence of 40 fair coin tosses, exact two-sided binomial tail under p=.5. A p-value is a tail probability under the assumed model, **not** the probability the null hypothesis is true, and not evidence of telepathy or any psi ability. Contextual links to psi-research methodology are not support for a psychic interpretation.

## Workflow

- Select one protocol and review its narrow question, methodology, boundary, next test and contextual references.
- Enter the parameters and a **prediction** before the model runs.
- Study the calculated result; descriptive SVG or H/T grid is explicitly a model or toy sequence, not measured observations.
- Record **an observation and an alternative or limitation**. Both must be populated.
- Explicitly capture up to 12 reviewed educational records in tab memory, remove individually, clear all, or export a JSON notebook.
- Export schema: \`369.hlj.educational-notebook.v1\`; each record: \`369.hlj.educational-run.v1\`.
- Source links are present as references to methods or related topics, not machine-audited provenance of the computed result.
- No automatic persistence, user accounts, external compute, file upload, analytics or medical claims.

## Data integrity

\`site/experiment-models.mjs\` contains pure functions for computation and record assembly; \`site/living-lab.js\` owns browser controls and session state. A captured standing-wave record excludes high-resolution SVG sample arrays. No model is given authority to reclassify any of the 179 founding Atlas topics.

The deterministic PRNG is used **only** for the educational fair-coin illustration. It is not a secure random generator, genuine experiment, or instrument.

## Manual acceptance checklist

- Change values for each protocol, compare expected and reported outcomes, reject invalid values.
- Verify a prediction is required *before* a run, and the prediction captured in a notebook record matches the one entered at run time.
- Verify the notebook requires both post-run notes, does not leak into other sessions or browsers, and exports a useful local JSON file only on click.
- Check keyboard, screen-reader announcements, dark-mode contrast, narrow screens, browser zoom, and reduced-motion behavior.
- Confirm no tracking or external requests beyond initial static local JSON and clicked reference links.
- Do not claim a physics lab, biological research result or scientific validation from a passing Node test.
