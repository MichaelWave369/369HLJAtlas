# HLJ Atlas Roadmap

## HLJ-001 — Founding Atlas
Import the full 179-topic list, build nine realms, searchable detail cards, three research questions per topic, 14 bounded connections, existing-project gateways, accessibility basics, tests and Pages workflow.

## HLJ-002 — Evidence dossiers (implemented as editorial starters)
Ten source-linked dossiers with limitations, alternatives, cultural notes, and two-way comparison. These are editorial starting points, not exhaustive source audits. Expand claim-level provenance and independent review before declaring any specific claim verified.

## HLJ-003 — Exploratory graph (implemented as first constellation)
179 topic nodes, nine realm hubs, fourteen existing provisional edges, ten dossier source pins, keyboard-operable topic index, pan/zoom, session-only notes and manual research packet export. This is a deterministic visualization, not inferred connections or reviewed scientific results. Continue with deeper claim-level source linkage and optional validated import after browser testing.

## HLJ-004 — Laboratory contracts (manual preview implementation)
Inspected source exports in AquaCymatics369 and Element Spiral Atlas; implemented four specific JSON shape recognizers, local-only file inspection, bounded allowlist, review and consent gate, optional explicit topic mapping, 12-record session, and explicit portable packet export. No remote APIs or actual automatic inter-project syncing. Complete manual browser and source-file qualification before claiming production readiness.

## HLJ-005 — PhiOS / Shasta Institute (digital-first gateway)
Six-stop accessible conceptual visitor walk, source-described PhiOS Web/Mobile/XR gateways, and a bounded synthetic 19-node passive `phi.spatial.scene.v1` export for explicit manual import into PhiOS XR. No actual campus, autonomous XR control or live integration claims. Independent browser and Quest acceptance required before labeling hardware-qualified.

## HLJ-006 — Living Research Laboratory (educational model preview)
Three interactive guided protocols: 1D string harmonics, exact Euler counts for five Platonic solids, and a deterministic 40-toss fair-coin null model. Users must state a prediction, inspect model outputs and limitations, and manually capture an observation and alternative explanation. Local session notebook exports portable JSON; no measured science or paranormal claims. Complete hands-on browser acceptance before describing the preview as production-qualified.

## HLJ-007 — Curated research verification and browser gate (proposed)
Ten narrowly restated claims linked to the existing 19 source references; clearly typed roles, no automatic truth classifications, an initially empty public correction ledger, local review proposal capture/export, and a required real-Chrome startup smoke in CI. Link status, retractions and scientific source correspondence remain **not independently audited**. Manual author and source review plus real interaction testing remain necessary.

## HLJ-008 — Source-quality audits and reviewed corrections
Verify primary-source links, metadata and retractions; build a documented editorial PR workflow with independently confirmed correction history; add browser interaction coverage and consider human review roles without instituting automated epistemic authority.

## Acceptance
Tests green, 179 unique topic IDs, every topic accessible by search, browse and keyboard, external links safe, clear review status and no hidden tracking. GitHub Actions passing is not a substitute for manual browser testing.
